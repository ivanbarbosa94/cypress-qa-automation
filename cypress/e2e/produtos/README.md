# Cypress QA Automation — Automation Exercise

Projeto de automação de testes E2E desenvolvido com Cypress para validação da aplicação [Automation Exercise](https://automationexercise.com/).

## Objetivo

Este projeto tem como objetivo demonstrar a aplicação de testes automatizados E2E utilizando Cypress, validando funcionalidades relacionadas a produtos, busca, navegação, carrinho e assinatura.

## Tecnologias utilizadas

- Cypress 15.20.1
- JavaScript
- Node.js
- Git
- GitHub

## Aplicação testada

[Automation Exercise](https://automationexercise.com/)

## Cenários automatizados

A suíte contém 7 casos de teste:

| ID | Cenário | Status |
|---|---|---|
| CT01 | Deve acessar a página de produtos | ✅ Aprovado |
| CT02 | Deve buscar um produto existente | ✅ Aprovado |
| CT03 | Deve realizar busca por produto inexistente | ✅ Aprovado |
| CT04 | Deve visualizar os detalhes de um produto | ✅ Aprovado |
| CT05 | Deve pesquisar produtos e verificar o carrinho | ✅ Aprovado |
| CT06 | Deve acessar a página de Test Cases | ✅ Aprovado |
| CT07 | Assinatura na página inicial | ✅ Aprovado |
